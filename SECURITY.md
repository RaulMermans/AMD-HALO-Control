# Security

## This repository

This is documentation, type contracts, one illustrative routing function and synthetic data. It contains no production code, configuration, environment variables, credentials, network addresses, hostnames, machine identifiers or real telemetry. The Control Room image was rendered from the synthetic files in `examples/`.

## The system it describes

See [docs/security-model.md](docs/security-model.md) for the principles: local-only operation, per-workload credentials, authorization before any work, registered-service-only execution, metadata-only activity history and identifier-free telemetry.

## Reporting

If you believe something here exposes sensitive information, please open a private security advisory on this repository instead of a public issue.
